# Учебные проекты на C++

Этот репозиторий содержит 10 учебных проектов, демонстрирующих основные принципы программирования на C++.

## Основные концепции
- Переменные и стандартный ввод-вывод
- Управляющие инструкции (if, switch, while, do...while)
- Циклы и работа со строками
- Массивы, указатели и ссылки
- Работа с STL библиотекой
- Функции и классы
- Управление памятью
- Наследование и полиморфизм

## Ключевые проекты

### 🃏 Blackjack (21)
Карточная игра с целью набрать 21 очко

**Технологии:**
- ООП (классы Card, Hand, Deck, Game)
- Динамическое управление памятью
- Алгоритмы рандомизации

### ❌⭕ Крестики-нолики
Классическая игра с ИИ-соперником

**Особенности:**
- Работа с указателями и ссылками
- Интеллектуальная система ходов
- Две версии реализации
