# Майкла Доусона "С++ через программирование игр" 

В процессе изучения книги Майкла Доусона "С++ через программирование игр" я написал 9 небольших программ, каждая из которых направлена на закрепление ключевых концепций языка C++. Эти проекты помогли мне разобраться в основах и продвинутых возможностях программирования, а также применить их на практике. 

Вот список тем, которые я освоил: 
- Переменные – работа с разными типами данных и их использованием. 
- Циклы – управление потоками выполнения с помощью for, while и do-while. 
- Массивы – хранение и обработка наборов данных. 
- Библиотека стандартных шаблонов (STL) – использование контейнеров, алгоритмов и итераторов. 
- Функции – создание и применение функций для структурирования кода. 
- Ссылки – работа с альтернативными именами переменных. 
- Указатели – прямое управление памятью и адресация. 
- Классы – основы объектно-ориентированного программирования (ООП). 
- Сложные классы – углубленное проектирование и взаимодействие объектов. 
- Работа с динамической памятью – выделение и освобождение памяти через new и delete. 
- Наследование и полиморфизм – создание иерархий классов и использование виртуальных функций.
